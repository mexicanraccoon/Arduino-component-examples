# Arduino-component-examples
A cache of wiring and code for learning new modules

There are a few goals of this repository. First, there will be multiple examples of many types of modules commonly used in Arduino.
As Arduino is open source, it will not be possible to cover every module, but hopefully it will be able to get you on your feet when starting out.
Wiring diagrams will also be added alongside the code for each module project. This will help you learn how the wiring goes along with the code.
